# CustomMapsFramework 1.1.1

Для Slendytubbies 3 Multiplayer 2.625, Unity 6000.0 и MelonLoader IL2CPP 0.7.3. Сетевая интеграция входит в NullServers 0.0.32. DLL обоих модов нужно обновить у хоста и клиентов.

## Установка карты

Папка `UserData/CustomMaps/MyMap` содержит `map.json` и сценовый AssetBundle `bundle`. Дополнительно поддерживаются `preview.png`, `waves.json`, `triggers.json` и музыка. Карты появляются в штатной вкладке S2 MAPS, как в предыдущем фреймворке.

```json
{
    "id": "author:my-map",
    "mapName": "My Map",
    "useDayAndNight": false,
    "size": 0,
    "collectMonster": "Newborn_Bot",
    "versusMonster": "Newborn",
    "survivalMonster": "Newborn_Bot",
    "isOutside": false,
    "version": "1.0.0",
    "dependencies": []
}
```

`id` — постоянный ID: строчные латинские буквы, цифры, `:`, `.`, `_`, `-`. Если его нет в старом JSON, ID автоматически получается из имени карты. `mapName` должен точно совпадать с названием сцены в бандле. При `useDayAndNight: true` нужны три сцены: `My Map (Day)`, `My Map (Dusk)`, `My Map (Night)`. Других сцен в этом бандле быть не должно. Имена не должны совпадать со штатными или другими картами. `size` — штатный индекс размера карты, `0` соответствует Small.

Используйте теги игры для точек появления: `TeamASpawn`, `TeamBSpawn`, `custardPos`, `ShopPoint`. Противникам нужна запечённая NavMesh. Сетевые объекты создаются через существующий NetBootstrap/FishNet, а не отдельный транспорт фреймворка.

`dependencies` содержит постоянные ID или имена пакетов CustomNPCFramework. При их использовании названия монстров в настройках карты/волн должны совпадать с `Name` NPC. NullServers проверяет объявленные зависимости перед созданием комнаты. Сам NPC должен быть включён в ADDONS.

## Волны

```json
[
    {
        "MaxNPC": 15,
        "WaveInfo": {
            "TotalCount": 25,
            "DefaultNPC": "Newborn_Bot",
            "NPCs": [
                { "NPCName": "TrainingMonster", "SpawnChance": 20, "IsBoss": false }
            ]
        }
    }
]
```

Индекс волн остаётся штатным, с нуля. Лимит одновременно активных NPC устанавливается перед штатным тиком спавна. На новой сцене Survival ждёт завершения загрузки FishNet и появления первого персонажа team1, чтобы не объявлять поражение во время сетевого спавна. После этого штатная проверка смерти всех игроков работает без изменений. `waves.json` необязателен: без него остаются штатные волны с монстром `survivalMonster`.

Музыка задаётся AssetBundle `music` с AudioClip `ambient`, `wave1`, `wave2` и т. д., либо папкой `music` с `ambient.mp3`, `wave1.mp3`, `wave2.mp3`. Порядковый номер файла начинается с 1. Отсутствующие файлы музыки пропускаются; для собственных волн без музыки используется ambient карты, если он есть. Назначенные AudioMixerGroup и громкость источников сохраняются.

## Триггеры

`triggers.json` — массив объёмов. Пример:

```json
[
    {
        "Id": "acid",
        "Type": "Damage",
        "Position": [5, 1, 0],
        "Size": [4, 3, 4],
        "Damage": 5,
        "CoolDown": 1
    },
    {
        "Id": "water",
        "Type": "Water",
        "Position": [12, 1, 0],
        "Size": [8, 3, 8],
        "Damage": 0,
        "Gravity": 4,
        "MaxFallSpeed": 10,
        "Blur": true,
        "WaterColor": "#35D8FFFF",
        "Priority": 1
    }
]
```

Типы: `Event`, `Damage`, `Kill`, `Water`, `Ambient`. `Id` должен быть уникальным. `Position` и `Rotation` заданы в мировых координатах сцены; `Size` — размеры BoxCollider. `Scene` ограничивает объём конкретной сценой дневного набора. Вместо создания нового объёма можно указать `Object`, путь от корневого объекта карты, и использовать его коллайдеры. На каждом таком объекте нужен один примитивный Collider или convex MeshCollider; дочерние коллайдеры становятся отдельными объёмами.

`Ambient` поддерживает `AmbientColor`, `Fog`, `FogColor`, `FogMode` (`Linear`, `Exponential`, `ExponentialSquared`), `FogDensity`, `FogStart`, `FogEnd`, `TransitionSpeed`, `Priority`. В пересекающихся зонах воды/окружения побеждает больший приоритет, при равенстве — последняя зона входа. После выхода из всех зон исходные параметры восстанавливаются. Чужие эффекты камеры не удаляются.

Контакты учитываются по игроку и его коллайдерам. Два коллайдера тела не дают два удара за один интервал. Урон и смерть идут через штатный метод `PlayerDamage.E10030` с его сетевой обработкой. Вода и окружение действуют на локального владельца игрока.

Для своих сценариев доступны `MapTriggers.Items`, `MapTriggers.Entered` и `MapTriggers.Exited`:

```csharp
MapTriggers.Entered += (trigger, player) =>
{
    if (trigger.Id == "checkpoint")
    {
        // Локальный владелец пересёк checkpoint.
    }
};
```

События локальные, по одному на игрока внутри каждого объёма. Сетевые изменения общего мира должен подтверждать хост через сетевой API вашего режима. Подписки нужно снимать при завершении вашего мода.

Старые группы `Killzones`, `Damage zones`, `Water zones` продолжают работать. Для Damage используется имя `damage cooldown`, для Water — `gravity damage cooldown`. Числа разбираются с точкой; при неверном/неполном имени берутся безопасные значения по умолчанию. Контейнер без коллайдера не превращается в триггер.

## NullServers и лобби

Хост публикует настоящую `MapName`, ID карты и хеш файлов. Поэтому карта отображается своим именем и загружается клиентом по той же сцене. Требуется только текущий пакет карты; лишние карты клиента не мешают входу. Проверяются `bundle`, `map.json`, `waves.json`, `triggers.json` и музыка. Байтовые отличия JSON тоже меняют хеш. Превью и название локальной папки не влияют на совместимость.

Если DLL/карты нет или файлы отличаются, Required Addons показывает пакет и его папку. Download открывает Discord. Проверка карты выполняется до загрузки сцены даже при большом наборе других аддонов. После выхода восстанавливается локальный каталог карт.

В настройках сервера можно переключаться между штатными картами и установленными кастомными пакетами, включая Day/Dusk/Night. Перед загрузкой новой сцены клиент проверяет её пакет и выбирает соответствующую карту. Если нужного пакета нет или он отличается, клиент выходит из комнаты с Required Addons вместо попытки загрузить отсутствующую сцену. Штатные карты работают без CustomMapsFramework. На официальных серверах создание комнаты с кастомной картой блокируется.

## Патчи текущей игры

- `DefaultSceneProcessor.BeginLoadAsync` и локальная загрузка Unity подготавливают карту до `Awake` игровых компонентов.
- `SurvivalMechanics.Awake` получает волны, `FixedUpdate` устанавливает лимит текущей волны перед штатным спавном.
- `LobbyMenu.Start` дополняет существующие списки карт, сохраняя UI NullServers.
- Патч, удалявший CustardBot на штатных картах, удалён.

Публичные методы старого Core сохранены. Добавлен `MapCatalog` API 1 для включения аддона и выбора согласованного содержимого комнаты.

Если установлен CustomGameModesFramework, обновите его до 1.1.4 из комплекта: в нём исправлена сериализация обычных режимов при смене раунда. Для работы самих карт установка фреймворка режимов не требуется.

В 1.1.1 сетевой объект комнаты получает имя __Room до штатного Awake на каждом участнике. Это требуется встроенной настройке оружия, которая ищет комнату по этому имени. MapCatalog.Installed возвращает все установленные карты, независимо от выбора текущей комнаты.
